流動單 怎麼輸入

紙本填好之後，照這幾步做
  1. 打開網址

    用 Chrome 開系統網址（建議加到「我的最愛」，或按「加到主畫面」變成手機圖示）。
    手機、平板、家裡的電腦都能開，不必在公司。

  2. 輸入共用帳號密碼

    第一次會出現登入畫面，打公司給的帳號密碼。
    登入一次之後會記住，之後直接進得去，除非你按登出。

  3. 按右上角的「＋ 靜子 ST」或「＋ 轉子 RO」

    看你手上那張紙是哪一種就按哪一個。按錯了退出去重按，還沒存的不會留下東西。

  4. 照紙上的格子，一格一格打進去

    畫面上的欄位順序跟紙本一模一樣，由上往下對著打。
    紙上沒填的就留空，不用湊。打到哪算哪，不必一次打完。

  5. 按右上角「儲存」

    存好之後，畫面最上面會出現一個單號，像 PT2026-0007。

  6. 把那個單號用筆寫在紙本的右上角

    這樣以後系統上查到某一筆，就找得到對應的那張紙。
    寫完紙本收進資料夾。

常見狀況
  1. 打到一半有事要走開

    直接關掉沒關係，內容會留在這台電腦上，下次打開同一張還在。
    但那只留在這台——換一台電腦就看不到了。所以能存就先按儲存。

  2. 存好之後發現打錯

    回清單頁 → 點那一列 → 按「開啟這張單」→ 改完再按儲存。改幾次都可以。

  3. 想找以前某個客戶怎麼做的

    在清單頁最上面那個搜尋框打字，客戶、模具、規格、軸孔都可以， 空白隔開表示「要同時符合」，例如 將凱 90*48 25。
    點任一列會展開「以前是怎麼做的」，不用開整張單。

  4. 按了儲存卻跳出失敗

    多半是網路斷了。
    你打的內容不會不見，等連上之後再按一次儲存就好。

資料存在哪　存在雲端（Supabase），不在任何一台電腦裡。 換電腦、換手機都看得到同樣的資料，也不怕哪台電腦壞掉。
